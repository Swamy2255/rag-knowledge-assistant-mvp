# New Hire Email and System Access

## Before day one

IT creates the new hire's email account and system access 2 business days before the start date, using the details from the HR onboarding form. The hiring manager receives a confirmation email with the new username and temporary password. If the confirmation has not arrived by the day before the start date, the manager should contact the Help Desk.

## First login

On day one, the new hire signs in at https://mail.company.example with the temporary password and is forced to set a new password of at least 12 characters. Multi-factor authentication must be set up during the first login using the Authenticator app. Access to the ticketing system, the wiki, and the file shares is granted automatically once MFA is complete.

## Access requests for extra systems

Access to systems beyond the standard set (for example, the production database or the finance system) requires a separate access request in the IT portal. The request must name the system, the business reason, and the approving manager. Standard requests are completed within 2 business days. Production database access also requires security team approval and takes up to 5 business days.

## When someone leaves

Managers must submit a leaver request in the IT portal on the employee's last day. Email and system access are revoked at 6:00 PM on the last working day. The manager is responsible for reassigning the leaver's open tickets before access is revoked.
