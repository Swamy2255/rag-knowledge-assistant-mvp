# Requesting Software

## Approved software list

The approved software list is published on the internal wiki under "IT / Approved Software". It includes standard tools such as the office suite, the VPN client, approved browsers, and the company chat app. Software on the list can be installed directly from the Software Center (Windows) or Self Service (Mac) with no approval needed.

## Requesting software that is not on the list

Submit a software request in the IT portal with the software name, version, vendor, business reason, and cost. The IT security team reviews the request for licence terms and security risks. Standard reviews take 3 business days. Requests for software that stores customer data or requires admin rights take up to 10 business days because they need a full security review.

## Installing software yourself

Do not install software from the internet without approval. Unapproved software can introduce security risks and licence violations. If you install unapproved software, IT may remove it remotely and your manager will be notified. Free and open-source software also needs approval unless it is already on the approved list.

## Licence renewals

IT tracks all software licences centrally. You will receive a renewal reminder 30 days before a licence expires. Reply to the reminder to confirm you still need the software; licences that are not confirmed are not renewed and the software is removed at expiry.
